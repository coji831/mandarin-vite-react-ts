## Feature fact-check summary (Architect Parts 1–4 verdicts, condensed)

- **Practice surfaces (Part 1)** — the practices format _holds up_ as an architecture: strategy registry + phase config + review strategy registry are the right shape. The defects are **data/registry bugs, not format flaws**. KEEP the pattern; FIX **R6** (char→radical vocabulary), **D6** (phase-3 gap + key-4 dup), **R7/D8** (P1 threshold), **R4** (guest P1-pass CTA); ENHANCE via P1 (10 quiz formats) + S5 (interleaved review); REMOVE none of the format machinery. Quiz status = **LIVE-BUT-BUGGY** (calibrated target = 10 formats); Review status = **LIVE-WORKING (registered) / FRACTURED (≥3 of 4 entry points — picker option, dashboard quick action, direct URLs)**.
- **Learning (Part 2)** — the Learn lane is **almost entirely data-driven**. The only real code touches are the **`frequencyRank` index + Core-300 derivation** (radicals), the **`hsk-word-counts.js`** utility (17,034→5,456 bug fix), the **`WordHskLevel` junction schema** (`@@id([wordId])` — lossy, 149 dup wordIds dropped; R10 → multi-level `@@id([wordId,hskLevel])`), and the **Pinyin phoneme seed/manifest wiring** (D14). No learn lane needs a UX/pedagogy restructure — the lane-split (`/learn` vs `/practices`) is already the correct IA.
- **AI/LLM (Part 4)** — the **S11 principle is fully verified in code** (all generation seams already `requireAuth`): P11 is a **confirmation, not a new lock** — except the **two TTS surfaces** (`POST /v1/tts` + passage-audio) which are `optionalAuth` today and are the **sole flip-candidates**; resolve in epic-25/29. All Tier-1 LLM work is **BUILD**; only mnemonic-gen, quiz-feedback, passage-gen, and TTS are live today.
