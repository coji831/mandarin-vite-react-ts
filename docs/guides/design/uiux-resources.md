## Notes on disposition

- **Adopted (✅)** — the resource's principle is already encoded in the repo (tokens, audit rules, rubric, archetypes). Re-reading is optional; the applied form lives in `uiux-fundamentals.md` §1.
- **Reference (📎)** — consult when designing a surface (density, layout anatomy, block patterns). **Never** copy Tailwind/shadcn output into the repo — it requires full token rework and the repo is no-Tailwind.
- **Deferred (⏳)** — Radix (#11) and UX Pilot (#20) are gated on **epic 31** (conversation panel) per `uiux-fundamentals.md` §1 #10/#11.
- **Moved (⚠️)** — Tailwind UI → Tailwind Plus (#25) and Windsurf → Devin Desktop (#26): use the new URLs only.
- **Fuselab (#29)** — the "playbook" is not a real, independent research artifact; do not cite it as evidence.
