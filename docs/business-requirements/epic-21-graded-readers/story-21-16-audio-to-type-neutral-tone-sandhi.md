# Story 21.16: Audio-to-Type Neutral Tone & Sandhi Extension

**Last Update:** July 24, 2026

## Description

**As a** learner,
**I want to** practice distinguishing neutral tone (tone 5) from full tones and receive sandhi-aware scoring in the Audio-to-Type quiz,
**So that** I can recognize toneless syllables and tone sandhi patterns in natural speech.

## Business Value

The Audio-to-Type quiz (Epic 18 feature in `features/foundations/`) currently only tests tones 1–4, ignoring the critical neutral tone (轻声/qīngshēng) that appears in ~15% of common Chinese words (particles like 吗, 了, 的, suffixes like 们, 子). Additionally, the quiz does not account for tone sandhi — a learner who types the dictionary tone instead of the spoken tone is marked wrong even though they know the correct underlying tone. This story extends the quiz with neutral tone support and sandhi-aware scoring logic, making it pedagogically accurate. Estimated effort is ~2-3 days.

## Acceptance Criteria

- [ ] Audio-to-Type quiz has a tone 5 (neutral) button alongside existing tones 1–4
- [ ] Neutral-tone questions generated from common particles: 吗, 了, 的, 着, 过, 们, 子 (and any other common neutral-tone syllables)
- [ ] Sandhi-aware scoring: quiz accepts either dictionary pinyin (tone 3) or spoken pinyin (tone 2) for known sandhi rules (3-3→2-3)
- [ ] QuizAttempt metadata extended to include `neutralToneTested` (boolean) and `sandhiQuestions` (count of sandhi-affected questions)
- [ ] Existing tone 1–4 quiz functionality remains unchanged
- [ ] Unit tests for sandhi-aware scoring logic
- [ ] Storybook stories updated for the extended Audio-to-Type quiz UI
- [ ] 0 lint errors across all changed files

## Business Rules

1. **Neutral Tone Button** — The quiz UI adds a fifth tone button labeled "5" or "轻声" next to the existing 1–4 buttons. The button follows the same visual pattern (colored circle with tone number).
2. **Question Generation** — Neutral-tone questions are generated by selecting common particles and suffixes that are pronounced as neutral tone in natural speech. The question audio is generated with the neutral tone pronunciation.
3. **Sandhi-Aware Scoring** — When scoring a 3-3 sandhi question (e.g., 你好 nǐ + hǎo → ní hǎo), the quiz accepts both the dictionary tone (3-3) and the sandhi tone (2-3) as correct. The scoring engine uses the existing ToneSandhiService (from Story 21.3) to determine acceptable answers.
4. **QuizAttempt Metadata** — The QuizAttempt model is extended with optional `metadata` JSON field containing `{ neutralToneTested: boolean, sandhiQuestions: number }`. This enables analytics on sandhi practice coverage.
5. **Backward Compatibility** — Existing Audio-to-Type quiz sessions are unaffected. The tone 5 button only appears when the question involves a neutral-tone syllable. Sandhi-aware scoring is transparent to the user — they see correct regardless of which valid tone they type.
